# 0020 — Documentation triage: retire the `*_REPORT.md` sprawl

- **Status:** Accepted (implemented in #17, #18, #19, #20, #50 — 4 canonical docs + archive sweep)
- **Date:** 2026-05-13
- **Deciders:** @ruv
- **Tags:** documentation, hygiene

Plus at the repo root: `BENCHMARKS_SUMMARY.md`,
`FINAL_SESSION_SUMMARY.md`, `IMPLEMENTATION_COMPLETE.md`,
`MIDSTREAMER_RENAME_STATUS.md`, `PUBLISHED_CRATES_ANNOUNCEMENT.md`,
`TEST_RESULTS.md`, `VALIDATION_STATUS.md`. Several violate the
project's own "never save working files / md to root" rule
(CLAUDE.md).

The architecture review agent already documented that these files:

- contradict each other (e.g. `ARCHITECTURE_SUMMARY.md` reports
  LOC=3,171 while the newer `DEEP_CODE_ANALYSIS.md` reports 27,811),
- reference pre-rename crate names that no longer exist
  (`GAP_ANALYSIS.md:42-48` lists `temporal-compare` rather than
  `midstreamer-temporal-compare`),
- describe a "3-layer architecture" while there are actually five
  parallel codebases in the tree (`ARCHITECTURE_SUMMARY.md:21`),
- have no dates, no authors, no version metadata.

A new contributor cannot tell which doc is current.

## Decision Drivers

- **One canonical doc per concept.** Architecture, benchmarks,
  security, getting-started, API reference — each gets one home.
- **Decisions go in ADRs.** Status reports do not.
- **Don't lose information.** Anything genuinely useful in the
  sprawling reports is harvested into the canonical homes; the rest
  is archived (kept in git history, but moved off the active tree).

## Considered Options

1. **Leave it.** Contradiction grows; new docs add to the pile.
2. **Delete everything outright.** Loses any salvageable content.
3. **Triage into Keep / Merge / Archive / Delete buckets**, with the
   bulk going to `docs/archive/` (kept readable but flagged as stale).
4. **Rewrite from scratch.** Highest effort; no salvage.

## Decision Outcome

**Chosen option: Option 3 — triage.**

Target end state for `docs/`:

```
docs/
├── ARCHITECTURE.md            # single authoritative architecture doc
├── BENCHMARKS.md              # generated by `cargo criterion`; see ADR-0009
├── SECURITY.md                # ongoing — links to ADR-0011..0015
├── GETTING_STARTED.md         # consolidates QUICK_START/QUICK_TEST_GUIDE
├── adr/                       # this directory; the decision history
└── archive/
    └── 2026-pre-cleanup/      # everything triaged out, dated, README-anchored
```

Bucket rules:

- **Keep:** `api-reference.md`, `quic-architecture.md` — both have
  unique content; merge into `ARCHITECTURE.md` and delete originals.
- **Merge:** `ARCHITECTURE_*.md`, `DEPENDENCY_GRAPH.md`,
  `DEEP_CODE_ANALYSIS.md`, `GAP_ANALYSIS.md` → `ARCHITECTURE.md`.
- **Merge:** all `BENCHMARK_*.md` files → `BENCHMARKS.md`
  (auto-generated per [ADR-0009](0009-honest-benchmarks.md); current
  prose moved to a section "Methodology" in that file).
- **Merge:** all `SECURITY_*.md` files → `SECURITY.md` (a list of
  current threats and pointers to the relevant ADRs).
- **Archive:** every `*_STATUS.md`, `*_SUMMARY.md`,
  `*_VALIDATION*.md`, `*_REPORT.md`, `FINAL_*.md`, `COMPLETE_*.md`,
  `COMPREHENSIVE_*.md`, `IMPLEMENTATION_*.md`, `COORDINATION_*.md`.
  Same goes for the root-level `BENCHMARKS_SUMMARY.md`,
  `FINAL_SESSION_SUMMARY.md`, `IMPLEMENTATION_COMPLETE.md`,
  `MIDSTREAMER_RENAME_STATUS.md`, `PUBLISHED_CRATES_ANNOUNCEMENT.md`,
  `TEST_RESULTS.md`, `VALIDATION_STATUS.md`.
- **Delete:** `Cargo.toml.backup` (root). Not docs but in the same
  sweep.
- **`docs/archive/README.md`** lists every archived file with the
  date it was archived and a one-line note on why.

### Positive consequences

- A new contributor opens `docs/` and sees 4 docs + the ADR
  directory, not 50 files.
- The root directory stops violating the project's own no-md-in-root
  rule.
- Information that was genuinely useful in the old reports gets
  harvested; nothing is silently lost.

### Negative consequences

- One-time triage effort. Roughly 1–2 days of careful reading. Best
  done in a single PR so reviewers can see the net diff.
- Anyone with bookmarks into the old report paths breaks. Mitigated by
  the `docs/archive/` README anchor + a top-level `docs/README.md`
  with redirects.

## Implementation notes

- Land this ADR first; do the triage in a follow-up PR titled
  `docs: triage per ADR-0020`.
- Generate the archive list automatically:

  ```bash
  rg --files docs/ | grep -E '_(REPORT|SUMMARY|STATUS|VALIDATION)\.md$' \
    > docs/archive/2026-pre-cleanup/MANIFEST.txt
  ```

- For each kept-or-merged doc, set up canonical headings, a "Status:
  current" line dated, and a "Supersedes:" list at the bottom.
- Update `README.md` (top-level) to link to the four canonical docs +
  the ADR index; remove links to the soon-archived docs.
- Add a `docs/lint.sh` check that fails CI if a new
  `*_REPORT.md`/`*_SUMMARY.md`/`*_STATUS.md` is added outside
  `docs/archive/`.
