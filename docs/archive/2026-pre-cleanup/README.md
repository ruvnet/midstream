# Archived documentation (2026-05-13)

This directory holds 44 markdown files that previously cluttered the
`docs/` directory and the repository root. They were moved here in
bulk by the [ADR-0020](../../adr/0020-docs-triage.md) implementation
(PR landing 2026-05-13) without inspection of content, with the
explicit goals of:

1. Stop having 50+ overlapping `*_REPORT.md` / `*_SUMMARY.md` /
   `*_STATUS.md` files at the top of `docs/` and at the repo root.
2. Stop violating the project's own
   [CLAUDE.md](../../../CLAUDE.md) rule against working files at the
   repo root.
3. Preserve every file in git history so anything actually useful
   can be harvested back into the canonical docs (`ARCHITECTURE.md`,
   `BENCHMARKS.md`, `SECURITY.md`, `GETTING_STARTED.md`) as those
   are written.

## What replaces them

Per [ADR-0020](../../adr/0020-docs-triage.md), the target end-state
for `docs/` is:

```
docs/
├── ARCHITECTURE.md            # single authoritative
├── BENCHMARKS.md              # generated by criterion (ADR-0009)
├── SECURITY.md                # links to ADRs 0011..0015
├── GETTING_STARTED.md
├── adr/                       # decision history
└── archive/
    └── 2026-pre-cleanup/      # this directory
```

The four top-level canonical docs are written incrementally as their
prerequisite ADRs ship. Until each is in place, this archive remains
the source for any harvestable content.

## Promise

- Nothing in this directory is deleted without a superseding PR that
  explicitly justifies the deletion.
- Anything genuinely useful gets harvested back into the canonical
  docs and only then is the archived original allowed to leave.
